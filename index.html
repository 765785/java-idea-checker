Java 环境与 IDEA 学生认证自检

浏览器出于安全限制无法读取别人电脑的环境变量，所以采用「本地脚本采集 + 网页判定渲染」的方式；所有数据只在用户自己电脑上流转，网页不发往任何服务器。

1

输入教育邮箱并生成脚本

Windows 10 / 11 适用。只需下载一个文件，双击即可检测。检测不会安装软件或修改环境变量。

生成后邮箱仅存此浏览器，并写入个人脚本。请勿转发。

再次下载检测 BAT

下载后这样操作

  1. 普通双击“一键检测.bat”，保持窗口打开。
  2. 等待“采集完成”，结果自动复制到剪贴板。
  3. 返回下方粘贴，或拖入同文件夹的 result.txt。

不要“以管理员身份运行”检测。如果下载被阻止，先核对来源，再查看文件“属性 → 解除锁定”；仍被拦截请联系管理员。

2

粘贴检测结果

支持 JSON、完整控制台原文，或直接拖入 result.txt。分析全部在浏览器内完成。

查看检测结论

修复会做什么？

有可用 JDK 时仅修当前用户的 JAVA_HOME 和 Path，无需管理员、无需联网。先在修复 BAT 同级建立 backup-时间戳目录，分别备份用户级和系统级原值；失败回滚本次修改。没有 JDK 时才联网安装，可能出现管理员确认。

系统 Path 旧 Java 若仍排在前面，需要管理员处理。不会改 CLASSPATH、删除 jetbra/pojie、修改 IDEA 登录或许可证。完成后关闭窗口，重新普通双击检测 BAT，再粘贴新结果。

最后一步：到 IDEA 里确认教育包

即使 EMAIL_EXACT 命中，也只证明「IDEA 里登录/绑定过这个教育邮箱」，不等于教育包已激活。

  1. 进入管理订阅（Manage Subscriptions）。
  2. 找到教育包；未显示时点击 Refresh license list。
  3. 选择教育包，点击 Activate。

官方激活说明 · IDEA 官方下载页（装完再回来做学生认证）

没有 JDK 或自动安装没有完成？

  1. ① 下载 JDK

    打开 Adoptium 官方下载页，选 Windows、JDK 25 和对应架构。无管理员权限时选 ZIP。

  2. ② 安装或解压

    运行安装包或将 ZIP 解压到可写目录。文件夹内应有 bin\java.exe 和 bin\javac.exe。放在个人 .jdks 目录可被自动发现。

  3. ③ 重新检测

    再次运行检测 BAT，粘贴新结果。受控电脑请联系机房管理员，也可先在 IDEA 的 Project SDK 中选择解压的 JDK。
