A1 下载检测工具压缩包

适用于 Windows 7 SP1 / 8.1 / 10 / 11 的桌面电脑。下载一个压缩包，解压后双击检测脚本；检测只采集信息，不会安装软件或修改环境变量。

此 ZIP 不包含个人邮箱，所有学生下载到的文件完全一致，可与公开 SHA-256 核对。教育邮箱判定会在检测结果出来后，由机器证据和 IDEA 当前账户人证共同完成。

脚本和网页不会上传任何数据；请不要把 result.txt、备份文件或导出报告公开转发。

如需核验下载文件，可在 GitHub Release 页面查看公开 SHA-256。

A2 运行检测脚本

  1. 右键 ZIP → 属性 → 若有“解除锁定”就勾选，再解压。
  2. 确认文件夹里有 4 个脚本文件和 1 个说明 txt：JavaCheck.bat、JavaCheck.ps1、JavaRepair.bat、JavaRepair.ps1、README_FIRST.txt。
  3. 普通双击 JavaCheck.bat，不要“以管理员身份运行”。窗口会显示四步进度。
  4. 窗口提示完成后，回到本页 A3 按 Ctrl+V；也可拖入同目录的 result.txt。

如果数量不对，说明可能被安全软件删除了文件。请到安全软件的隔离区/恢复区找回并按其界面添加为信任项；不要关闭安全软件或设置全局排除。

被安全软件或 SmartScreen 拦截怎么办？
  1. 确认 ZIP 来自本页面或项目公开 Release，而不是聊天群里的未知转发文件。
  2. 右键下载的 ZIP → 属性 → “解除锁定”（若该项存在）→ 应用，再解压。
  3. 若被隔离，到安全软件的隔离区恢复这个具体文件；学校机房请联系管理员处理。

本工具不下载或执行远程内容。检测脚本为可阅读的 PowerShell 文件；不建议关闭防护或添加全局排除。

修复会做什么？

有可用 JDK 时，修复只调整当前 Windows 账户的 JAVA_HOME 和用户 Path，不联网、不申请管理员权限。它会先在解压文件夹建立 backup-时间戳 目录，分别备份用户级和系统级 JAVA_HOME / Path；失败只回滚本次改过的值。

没有可用 JDK 时才可能请求管理员权限以安装 JDK。不会改 CLASSPATH、删除 jetbra/pojie、修改 IDEA 登录或许可证。修复成功后，请关闭窗口，普通双击 JavaCheck.bat 重新检测。

没有 JDK 或自动安装没有完成？

  1. ① 下载 JDK

    打开 Adoptium 官方下载页，选 Windows、JDK 25 和对应架构。无管理员权限时可选 ZIP。

  2. ② 安装或解压

    运行安装包或将 ZIP 解压到可写目录。文件夹内必须同时有 bin\java.exe 和 bin\javac.exe。

  3. ③ 回来复检

    普通双击 JavaCheck.bat，粘贴新结果。受控电脑请联系机房管理员，也可先在 IDEA 的 Project SDK 中选择解压的 JDK。
